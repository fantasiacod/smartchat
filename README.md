# Smart Chat Agent — المساعد الذكي وخدمة العملاء

نظام محادثة مستقل يُركّب على أي موقع (ووردبريس، سلة، زد، Shopify، HTML...) بسطر واحد، مع لوحة تحكم كاملة.

## المميزات

| الميزة | التفاصيل |
|---|---|
| 🌳 شجرة ردود | عقد وأزرار قابلة للتعديل بالكامل من اللوحة: انتقال، رد نصي، استعلام قاعدة بيانات، تحويل لموظف، رابط، إنهاء |
| 📚 تعلّم ذاتي | إذا لم يجد البوت إجابة يحوّل لموظف فوراً، ورد الموظف يُحفظ تلقائياً في قاعدة المعرفة ليجيب البوت عن نفس السؤال مستقبلاً (يفهم الصياغات المختلفة بالعربية) |
| 🗄️ ربط أي قاعدة بيانات | MySQL، PostgreSQL، SQL Server، Oracle، MongoDB، Google Sheets، ملفات Excel/CSV، SQLite، REST API — تقليدية أو سحابية. يجلب بيانات المستفيد وحالة الطلب والملاحظات، ويسأل المستفيد تلقائياً عن المتغيرات الناقصة (رقم الطلب، الجوال...) |
| 🙋 تحويل بشري | ليس ضمن القائمة: بدون أي ذكاء اصطناعي مدفوع، البوت يحوّل فوراً عندما لا يعرف الإجابة، أو عندما يطلب المستفيد موظفاً. بمجرد التحويل يتوقف البوت فوراً وتنتقل المحادثة للموظف مباشرة (WebSocket) مع تنبيه صوتي وإشعار متصفح |
| 🗂️ سجل كامل | كل رسالة محفوظة، بحث وفلترة (من أغلق المحادثة، التقييم، التحويل، التاريخ)، تصدير نصي |
| ⏱️ مدة الحفظ | تحديد عدد أيام حفظ المحادثات (حذف تلقائي)، وإغلاق تلقائي عند عدم النشاط |
| 🚪 الإغلاق | إغلاق المستفيد أو الموظف أو النظام يظهر فوراً في اللوحة ومميّز في السجل |
| ⭐ التقييم | نجوم بأنصاف (عدد النجوم قابل للتعديل)، اللون يتدرج من الأحمر (نصف نجمة) إلى الأخضر (الحد الأعلى) + ملاحظة |
| 🎨 التخصيص | اللون، صورة الزر، صورة البوت، الموضع، الحجم، كل النصوص، رسالة منبثقة، نموذج بيانات قبل المحادثة، معاينة حية |
| 👥 المستخدمون | إنشاء مستخدمين بثلاث صلاحيات: مدير / مشرف / موظف، تعطيل وحذف، تحويل محادثة بين الموظفين، سجل عمليات |
| 🌐 مواقع متعددة | كل موقع بمفتاح وإعدادات وشجرة وقاعدة معرفة مستقلة، وكل المحادثات في لوحة واحدة |
| 🔢 قائمة مرقّمة | بعد الترحيب تظهر قائمة رئيسية مرقّمة (اكتب 1، 2، ١، ٢ أو اضغط الزر) قابلة للتعديل بالكامل |
| 🏢 معلومات الجهة | نبذة وتاريخ، رؤية ورسالة، أقسام وأرقام، ساعات العمل، حسابات التواصل، بطاقات مخصصة — يجيب عنها البوت تلقائياً |
| 📍 الخريطة والفروع | عند السؤال عن الموقع تُرسل خريطة Google داخل المحادثة مع زر الاتجاهات. ولعدة فروع: قائمة مرقّمة بالفروع ثم خريطة الفرع المختار وأرقامه وأوقاته وصوره، ويفهم «فرع جدة» مباشرة |
| 🖼️ الوسائط | البوت والموظف يرسلان صوراً وفيديو وPDF ويوتيوب داخل المحادثة (مثل شرح طريقة التسجيل) |
| 📝 الشكاوى والاقتراحات | نموذج (اسم، جوال، نص) برقم وتاريخ، لوحة متابعة وحالات ورد، إشعار بالبريد SMTP / SMS (تقنيات، يونيفونك، مسجات، Twilio، مخصص) / واتساب (يدوي أو Business API)، تقرير Excel ونسبة الشكاوى |

| 🌍 3 لغات | العربية والإنجليزية والأردية مع اكتشاف تلقائي وتبديل يدوي، وترجمة لكل عقدة وزر |
| 🕌 زخارف | نجمة اثنا عشرية، حروف عربية، نجمة ثمانية، سدو سعودي، نجدي، أرابيسك، مشربية… للمحادثة وللوحة التحكم |
| 📊 تقارير | لوحة إحصائيات (أتمتة، رضا، أوقات الذروة، من أنهى المحادثة) وتقارير الموظفين (الكل / موظف / مجموعة) مع تصدير Excel |
| 🔌 تركيب سهل | إضافة ووردبريس جاهزة ومربوطة تُنزّل من اللوحة، وخطوات لسلة وزد وShopify وGTM، وكشف تلقائي لحالة التركيب |
| 🧠 الخريطة الذهنية | لوحة تفاعلية تتحرك بحرية (سحب، تكبير، ترتيب تلقائي بحركة سلسة)، وربط سؤال بسؤال أو أكثر فتظهر الأسئلة المرتبطة كأزرار مرقّمة بعد الإجابة. كل ما يعرفه البوت مصنّف بأيقونات وألوان؛ ما يجيب عنه الموظف يُضاف تلقائياً، والأسئلة غير المُجابة تظهر باللون البرتقالي لتُجاب بضغطة |
| 🏢 عن الجمعية | أقسام (نبذة، رؤية، رسالة، أهداف، طريقة التسجيل…) لكل منها أيقونة ولون أو شعار الجمعية، تظهر كقائمة مرقّمة للمستفيد |
| 🏦 الحسابات البنكية | تصنيفات رئيسية (الحساب العام، الزكاة…) تحت كل منها حسابات في بنوك مختلفة، مع التحقق من الآيبان وزر نسخ للمستفيد |
| 🎉 زخرفة المناسبات وصورك | زخارف رمضان والعيد واليوم الوطني، وتبديلها تلقائياً في مواعيدها (هجري أم القرى)، وزخرفة من شعار الجهة أو من صورك (حتى 8 صور). شعارات PNG تظهر بدون خلفية بيضاء |
| 🖼️ خلفية خاصة وشريط علوي | ارفع تصميمك الخاص كخلفية للمحادثة (أو اختر خلفية جاهزة)، والزخرفة تبقى فوقها: في المحادثة والشريط العلوي، أو الشريط العلوي فقط، أو بدونها. ويمكن إظهار الموقع/العنوان والبريد في الشريط العلوي بجانب الرقم الموحّد — كلها اختيارية |
| 🧭 معالج الإعداد الأول | أول تشغيل على أي استضافة جديدة تظهر صفحة إعداد: اختيار قاعدة البيانات (SQLite، Supabase/PostgreSQL، MySQL، MongoDB، Firebase، SQL Server) مع اختبار الاتصال، ثم إنشاء حساب المدير (الاسم، البريد، كلمة المرور). محمية برمز إعداد يظهر في سجلات الاستضافة |
| 👥 موظف لكل موقع/فرع | يمكن ربط أي موظف بموقع واحد فقط، فلا يرى إلا محادثاته وبياناته (اختياري — بدون ربط يرى كل المواقع كالسابق) |
| 🧮 حاسبة الاستحقاق | زر واحد «حساب آلية الاستحقاق» في القائمة (يظهر أو يُخفى) وبداخله كل البرامج (يمكن إخفاء أي برنامج). لكل برنامج: أسئلة (رقم/مبلغ، اختيار، نعم/لا)، حسابات مثل دخل الفرد، شروط «غير مؤهل إذا…» تُفحص بعد كل إجابة، معادلة قيمة الاستحقاق بحد أدنى وأعلى، رسائل النتيجة، زر التقديم، تجربة فورية، وإحصائيات النتائج وأكثر أسباب الرفض |
| 🗄️ أكثر من قاعدة بيانات | قاعدة رئيسية + قواعد/واجهات API إضافية + استعلامات مخصصة بكلمات مفتاحية (موعد الصرف، ملف المستفيد…) |
| 💾 النسخ الاحتياطي | تنزيل واسترجاع بضغطة، نسخ تلقائي مجدول إلى مجلد وإلى البريد، وتصفير كامل محمي بكلمة المرور |
| 🔗 قابل للتطوير | Webhooks موقّعة + REST API + دليل المطورين DEVELOPERS.md |
| 🛡️ فحص الأمن والتحمّل | 0 ثغرات في المكتبات، ترويسات أمان، حماية من الإغراق، ~5,500 محادثة/دقيقة على خادم بنواتين — التفاصيل في SECURITY.md |
| 🕘 أوقات العمل | جدول لكل يوم (يعمل/مغلق، من، إلى). خارج الأوقات يكتب البوت أوقات العمل ويطلب الاسم والجوال فقط، ويُسجَّل «طلب تواصل» برقم (R-1001) للرد عليه في أيام العمل — مع خيار تفعيل/تعطيل التحويل للموظف خارج الأوقات |
| 🔐 الأمان | توثيق هوية العملاء بتوقيع HMAC، استعلامات SELECT فقط، تقييد النطاقات المسموحة، تحديد محاولات الدخول |

## التشغيل

**المتطلبات:** Node.js 22 (أو Docker).

```bash
cd server
cp .env.example .env        # عدّل بريد وكلمة مرور المدير
npm install
npm start
```

افتح `http://localhost:3000/admin/` وسجّل الدخول بحساب المدير من ملف `.env`
(الافتراضي إن لم تعدّله: `admin@example.com` / `admin123` — غيّره فوراً من صفحة "حسابي").

**بـ Docker:**
```bash
cd server && cp .env.example .env && docker compose up -d
```

> للإنتاج: ضع الخادم خلف نطاق بشهادة HTTPS (مثل `chat.yoursite.com`) عبر Nginx أو Caddy، مع تمرير WebSocket.
> مثال Caddy: `chat.yoursite.com { reverse_proxy localhost:3000 }`

## التركيب على موقعك

### أي موقع
من اللوحة ← **التركيب على المواقع** انسخ السطر والصقه قبل `</body>`:
```html
<script src="https://chat.yoursite.com/widget.js" data-site="SITE_KEY" async></script>
```

### ووردبريس
1. ارفع `smart-chat-agent.zip` من **إضافات ← أضف جديد ← رفع إضافة** وفعّلها.
2. **الإعدادات ← Smart Chat**: أدخل رابط الخادم، مفتاح الموقع، والمفتاح السري.
3. الإضافة تتعرف على العملاء المسجّلين دخولهم تلقائياً (موقّع بـ HMAC). ويمكنك وضع زر بالاختصار `[smart_chat_button]`.

## ربط قاعدة البيانات

من **الإعدادات ← قواعد البيانات** اختر النوع وضع رابط الاتصال. الأنواع المدعومة:

| النوع | أمثلة (تقليدي / سحابي) | رابط الاتصال |
|---|---|---|
| MySQL / MariaDB | ووردبريس، cPanel، PlanetScale، AWS RDS، Azure | `mysql://user:pass@host:3306/db` (أضف `?ssl=true` للسحابي) |
| PostgreSQL | Supabase، Neon، AWS RDS، Google Cloud SQL | `postgres://user:pass@host:5432/db` |
| SQL Server | SQL Server داخل الجهة، Azure SQL | `Server=host,1433;Database=db;User Id=u;Password=p;Encrypt=true` |
| Oracle | Oracle Database، Oracle Cloud (بدون تثبيت Oracle Client) | `oracle://user:pass@host:1521/service` |
| MongoDB | MongoDB، MongoDB Atlas | `mongodb+srv://user:pass@cluster.mongodb.net/db` |
| قاعدة بيانات موقع ووردبريس | أي جدول في قاعدة بيانات الموقع، حتى في الاستضافات التي تمنع الاتصال الخارجي (InfinityFree…) | رابط الموقع + اختيار الجداول من إعدادات الإضافة |
| Google Sheets / CSV | جدول Google مشارك أو أي رابط CSV | رابط الجدول مباشرة |
| ملف Excel / CSV | رفع ملف .xlsx أو .csv من اللوحة | زر «رفع ملف» |
| SQLite | ملف قاعدة بيانات على نفس الخادم | `/path/to/file.db` |
| REST API | Firebase، Airtable، أنظمة ERP / CRM | رابط API + Headers |

- في Google Sheets والملفات: الصف الأول = أسماء الأعمدة، والجدول اسمه `data` → `SELECT next_date FROM data WHERE id_number = :id_number`
- في MongoDB يُكتب الاستعلام JSON: `{"collection":"orders","filter":{"order_no":":order_no","phone":":phone"}}`
- **المربعات:** من نفس الصفحة أضف أي معلومة يسألها البوت (رقم الملف، الاسم، تاريخ الميلاد…) بسؤالها ونوعها (أرقام، جوال، هوية، بريد، تاريخ، نص). البوت يتحقق من الإجابة ويعيد السؤال إن كانت خاطئة، ولا يسأل مرتين في نفس المحادثة. ويمكن حذف أي مربع.
- **🪄 بناء الاستعلام بدون كتابة:** يقرأ الجداول والأعمدة من قاعدة البيانات، فتختار بماذا يبحث البوت وماذا يعرض، ويكتب الاستعلام وقالب الرد تلقائياً لأي نوع.
- **أي رقم مسجّل:** في «بناء الاستعلام» اختر «أي رقم مسجّل» وحدّد الأعمدة (رقم الطلب، الهوية، الجوال…): يسأل البوت سؤالاً واحداً ويعرض كل ما يخص المعاملة. أي سطر قيمته فارغة (مثل «السبب») يُخفى تلقائياً، و`{*}` في قالب الرد يعرض كل الأعمدة المعبأة.
- قاعدة بيانات تجريبية جاهزة للتجربة على Supabase: `test-database/supabase-demo.sql`

ثم اكتب الاستعلامات بمتغيرات تبدأ بـ `:` — البوت يطلبها من المستفيد تلقائياً:
```sql
SELECT status, notes FROM orders WHERE order_no = :order_no AND phone = :phone
```
- أي عمود يرجع يمكن استخدامه في قالب الرد: `{status}` `{notes}` ...
- الملاحظات تظهر للمستفيد فقط إن وُجدت.
- يوجد زر **اختبار الاتصال** قبل الحفظ، وبيانات تجريبية جاهزة (طلب `1001` بجوال `0500000001`).
- 🔒 يُنصح بشدة بمستخدم قاعدة بيانات بصلاحية قراءة فقط. اشتراط الجوال مع رقم الطلب يمنع أي شخص من الاستعلام عن طلبات غيره.

## كيف يعمل البوت

```
رسالة المستفيد
  ├─ ينتظر متغيراً (رقم طلب/جوال)؟ ← يكمل الاستعلام
  ├─ تطابق زراً معروضاً؟ ← ينفذ إجراءه
  ├─ يطلب موظفاً؟ ("موظف"، "خدمة العملاء"...) ← تحويل فوري
  ├─ يسأل عن طلب؟ ("حالة طلبي"...) ← استعلام من قاعدة البيانات
  ├─ يطابق سؤالاً في قاعدة المعرفة؟ ← يجيب
  └─ لا إجابة ← تحويل لموظف + حفظ السؤال ← رد الموظف يُحفظ كإجابة
```
الكلمات المفتاحية وحد التطابق والرسائل كلها قابلة للتعديل من **سلوك البوت**.

## التخزين (3 خيارات)

| `DB_TYPE` | الاستخدام |
|---|---|
| `sqlite` (افتراضي) | VPS أو أي استضافة بقرص دائم |
| `supabase` | استضافات مجانية تمسح الملفات (Render) — ضع رابط Session pooler في `DATABASE_URL` |
| `mysql` | استخدام MySQL من استضافتك العادية — `DATABASE_URL=mysql://user:pass@host:3306/db` |

تشغيل مجاني بالكامل: **Render (Free) + Supabase (Free) + UptimeRobot** — الخطوات في دليل التشغيل، قسم 12. ملف `server/render.yaml` جاهز.

## ربط قاعدة بيانات موقع ووردبريس (عبر الإضافة) — جسر ووردبريس

لا يصل البوت لقاعدة البيانات مباشرة؛ الإضافة تقرأ من داخل الموقع:
1. حدّث الإضافة (الإصدار 2.2) من صفحة «تركيب المحادثة».
2. في ووردبريس: الإعدادات ← Smart Chat Agent ← اختر الجداول المسموحة من قاعدة ووردبريس، و/أو فعّل «قاعدة بيانات خارجية» (MySQL / MariaDB منفصلة يصل إليها خادم الموقع) واختر جداولها. بيانات الاتصال تبقى في الموقع. جداول حسابات ووردبريس وإعداداته لا تظهر.
3. في لوحة البوت: قواعد البيانات ← النوع «قاعدة بيانات موقع ووردبريس» ← رابط الموقع ← «عرض الجداول».
4. الاستعلامات ← «🪪 جاهز: بياناتي برقم الهوية» ← اختر الجدول وعمود رقم الهوية ← «اعرض كل الأعمدة» ← «➕ زر في القائمة الرئيسية».

🔒 لا تُرسل أي جملة SQL إلى الموقع: الطلب = جدول مسموح + أعمدة + قيمة بحث، موقّع بـ HMAC، صالح دقيقتين ولمرة واحدة، والقراءة فقط (حتى 5 صفوف).
