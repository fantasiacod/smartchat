WordPress plugin / إضافة ووردبريس
=================================
Upload "smart-chat-agent.zip" as-is from:
WordPress Dashboard > Plugins > Add New > Upload Plugin

ارفع الملف smart-chat-agent.zip كما هو بدون فك الضغط من:
لوحة ووردبريس > إضافات > أضف جديد > رفع إضافة

The folder "smart-chat-agent" is the source code of the same plugin.
المجلد smart-chat-agent هو الكود المصدري لنفس الإضافة (لا تحتاجه للتركيب).
