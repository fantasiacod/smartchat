Adds the Smart Chat Agent widget (decision-tree bot, knowledge base, order lookups, human handoff, ratings) to your WordPress site.

== Installation ==
1. Upload the plugin zip from Plugins > Add New > Upload.
2. Activate it, then go to Settings > Smart Chat.
3. Enter the server URL, site key and identity secret from your Smart Chat dashboard (Install page).
